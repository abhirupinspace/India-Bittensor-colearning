# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Docusaurus 3.7 static site hosting the **Bittensor Co-Learning Camp India** curriculum (HackQuest × Bittensor). Almost all content is Markdown/MDX in `docs/`; very little custom code.

## Commands

`bun.lock` is committed — use bun. README mentions yarn; either works, just don't mix.

```bash
bun install           # install
bun start             # dev server on :3000 (hot reload)
bun run build         # static build → build/
bun run serve         # serve built site locally
bun run typecheck     # tsc, no emit
bun run clear         # clear .docusaurus cache (use when sidebar/config changes don't show)
```

No test suite. No linter configured.

## Architecture

- **Docs at site root**: `routeBasePath: '/'` in `docusaurus.config.ts` — docs are served at `/`, not `/docs/`. There is no `src/pages/index.tsx`-as-landing setup beyond the file present; the curriculum overview is the de facto home via `slug: /overview`.
- **Auto-generated sidebar**: `sidebars.ts` uses `{type: 'autogenerated', dirName: '.'}`. Order is controlled by:
  - Numeric filename prefixes (`00-overview.md`, `01-what-is-web3.md`)
  - `_category_.json` files in each phase folder (sets label, position, generated-index page)
  - Folder names like `Phase-0-Prerequisites/`, `Concept-1-Introduction/`, `GP-1-Sportstensor-SN41/` form the URL path — renaming a folder breaks all links to it.
- **Curriculum structure** (folder = URL segment):
  - `docs/Phase-0-Prerequisites/` — Web3 / AI primers
  - `docs/Phase-1-Fundamentals/Concept-{1,2}-…/` — Bittensor architecture, core subnets
  - `docs/Phase-2-Building/GP-{0,1,2}-…/` — guided projects (local mining, SN41 Sportstensor, SN13 Data Universe)
  - `docs/Phase-3-Resources/`
- **Broken links throw**: `onBrokenLinks: 'throw'` — a typo in any internal link fails `bun run build`. Run `bun run build` before claiming a docs change is done; `bun start` does not enforce this.
- **Mermaid enabled** via `@docusaurus/theme-mermaid` (`markdown.mermaid: true`). Use ```` ```mermaid ```` fences directly.
- **Local search**: `docusaurus-plugin-search-local` with `docsRouteBasePath: '/'` — matches the root-mounted docs. If `routeBasePath` changes, update this too.
- **Prism extras**: `bash, python, json, yaml, toml, rust` are pre-registered for code fences.

## Conventions

- Frontmatter: `sidebar_position`, `title`, `description`, `slug` — `slug` overrides folder-derived URL (e.g., `00-overview.md` uses `slug: /overview`).
- Internal links: prefer relative paths or slugs that match the rendered URL (root-mounted), not `/docs/...`.
- Static assets live in `static/` and are referenced via `useBaseUrl('/img/...')` in MDX.
- Bittensor / OTF marks: usage governed by Opentensor Graphic Standards (see README). Don't relabel as official OTF content.
