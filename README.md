# Bittensor Co-Learning Camp

Curriculum for **Bittensor Co-Learning Camp India** (offline). A HackQuest × Bittensor program that takes students from zero (no Web3, no AI background) to running production miners on Sportstensor (SN41) and Data Universe (SN13).

This is a [Docusaurus](https://docusaurus.io/) site.

## Local development

```bash
yarn install
yarn start
```

Opens http://localhost:3000.

## Build

```bash
yarn build
```

Static files land in `build/`.

## Curriculum structure

- **Phase 0 — Prerequisites**: Web3, AI, centralized vs decentralized AI, why Bittensor
- **Phase 1 — Fundamentals**: Bittensor architecture, tokenomics, core subnets (Chutes, Data Universe, Sportstensor, Ridges)
- **Phase 2 — Building**: Hands-on miner setup — local mining intro, then guided projects on SN41 and SN13
- **Phase 3 — Resources**: Official docs, explorers, repos, community, glossary
