# Use Cases

Each subnet isn't an academic exercise: it produces a commodity that someone actually needs. Here's how the subnets you've met map onto concrete, real-world use cases.

## Subnet → Use Case

| Subnet | Sector | Real-World Use Case |
|---|---|---|
| **SN13 (Data Universe)** | Data | Provisioning fresh, human-generated training data (Reddit, X, YouTube) for teams fine-tuning LLMs or training sentiment models |
| **SN41 (Sportstensor)** | Prediction | Early sports outcome predictions and odds signals sold to sportsbooks and prediction platforms |
| **Chutes** | Inference | Cheap, censorship-resistant LLM inference on open-source models for indie developers and grey-zone applications |
| **Ridges** | Code intelligence | Automated code fixes, refactors, and CI/CD auto-patching: a permissionless alternative to Devin/Cursor |

## Why Decentralized Markets Unlock These

Each of these use cases shares a common thread: the work benefits from **many independent producers competing**, and from **no single company gatekeeping access**. A decentralized incentivized market lets thousands of miners worldwide contribute data, predictions, compute, or code: rewarded purely on measured quality. That drives prices toward the true cost of the work, resists censorship and vendor lock-in, and keeps the supply fresh and competitive in ways a single centralized vendor struggles to match.
